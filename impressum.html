2. Welche Daten werden erhoben?

Im Rahmen einer Bewerbung über unser Bewerbungsportal können folgende personenbezogene Daten erhoben werden:

- Discord-Benutzername
- Alter
- RP-Name (In-Game-Name)
- Roblox-Benutzername
- Bewerbungsantworten und Motivationsschreiben
- Weitere Angaben aus den Bewerbungsformularen

3. Zweck der Datenverarbeitung

Die erhobenen Daten werden ausschließlich zur Bearbeitung, Prüfung und Verwaltung von Bewerbungen für das Communityprojekt Emergency Rostock verwendet.

Dazu gehören insbesondere die Kontaktaufnahme, die Bewertung der Bewerbungen und die Mitteilung von Bewerbungsentscheidungen.

4. Speicherung der Daten

Die Bewerbungsdaten werden abhängig von der technischen Umsetzung digital gespeichert.

Zugriff auf die Bewerbungsdaten erhalten ausschließlich hierzu berechtigte Personen, die an der Bearbeitung der Bewerbungen beteiligt sind.

Die Daten werden nur so lange gespeichert, wie dies für die genannten Zwecke erforderlich ist oder gesetzliche Aufbewahrungspflichten bestehen.

5. Weitergabe von Daten

Eine Weitergabe der Bewerbungsdaten an unberechtigte Dritte erfolgt nicht.

Technische Dienstleister können im Rahmen des Hostings oder der Speicherung Zugriff auf Daten erhalten, soweit dies für den Betrieb des Portals erforderlich und rechtlich zulässig ist.

6. Discord und externe Dienste

Im Rahmen des Bewerbungsverfahrens kann Discord zur Kommunikation und Benachrichtigung verwendet werden.

Hierbei gelten zusätzlich die Datenschutzbestimmungen des jeweiligen Dienstanbieters.

7. Deine Rechte

- Recht auf Auskunft über deine gespeicherten Daten
- Recht auf Berichtigung unrichtiger Daten
- Recht auf Löschung deiner Daten
- Recht auf Einschränkung der Verarbeitung
- Recht auf Datenübertragbarkeit
- Recht auf Widerspruch gegen bestimmte Verarbeitungen
